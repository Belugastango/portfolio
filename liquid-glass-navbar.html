Apple Liquid Glass Navigation Specs

Engineered precisely to the user's specification and reference photograph. This component showcases Apple's Liquid Glass material physics with high-performance backdrop filtering, dual specular light rims, and an active 3D convex refractive pebble.

Back to Divine Interiors Site

1. Geometry

Floating pill shape centered horizontally with viewport top offset.

border-radius: 32px;

2. Material

GPU-accelerated backdrop blur with ultra-low-opacity tint.

backdrop-filter: blur(20px) saturate(180%);

3. Specular Highlights

Multi-layer hairline stroke + sharp top inset box-shadow.

inset 0 1.5px 1.5px 0 rgba(255,255,255,0.55);

4. Motion Physics

Smooth spring-based scale & translate transitions on hover and click.

cubic-bezier(0.16, 1, 0.3, 1);

Tailwind CSS & Clean CSS Implementation

/* Pure CSS Apple Liquid Glass Pill */

  background: rgba(26, 28, 32, 0.65);

  border: 1px solid rgba(255, 255, 255, 0.18);
  box-shadow:
    inset 0 1.5px 1.5px 0 rgba(255, 255, 255, 0.55),
    inset 0 -1px 1px 0 rgba(0, 0, 0, 0.4),
    0 24px 48px -12px rgba(0, 0, 0, 0.45);
  transition: transform 0.35s cubic-bezier(0.16, 1, 0.3, 1),
              box-shadow 0.35s cubic-bezier(0.16, 1, 0.3, 1);
}
